# How to Use This Vault

1. Unzip and open the folder in Obsidian (**Open folder as vault**).
2. Open **Graph view** (Ctrl/Cmd + G). Colors are preconfigured: each phase has its own color, hubs are yellow, strategy notes are teal and resources are pink.
3. In the graph, use **Filters > Tags** or search `tag:#phase-2` to isolate one phase. Use the **Local graph** on any topic note to see its prerequisites and what it unlocks.
4. Each topic note has a status in its properties: `todo`, `doing`, `done`. Change it as you progress. The [[Dashboard]] note summarizes status if you install Dataview.
5. Use the notes in `06 Templates` with the core **Templates** plugin (already pointed at that folder): [[Problem Log Template]], [[Contest Review Template]], [[Weekly Review Template]], [[Topic Note Template]].
6. Log every problem in [[Problem Log]] and every mistake in [[Mistake Log]].
