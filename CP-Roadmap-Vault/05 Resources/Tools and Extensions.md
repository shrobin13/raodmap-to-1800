# Tools and Extensions

- **cph (Competitive Programming Helper)** for VS Code: fetches samples and runs tests.
- **Carrot** browser extension: shows predicted rating changes on Codeforces.
- **Codeforces Problemset filters**: filter by tag, rating and solved status.
- **g++ with sanitizers**: `-fsanitize=address,undefined -D_GLIBCXX_DEBUG` ([[C++ Setup and Fast IO]]).
- **Stress testing scripts**: [[Stress Testing]].
