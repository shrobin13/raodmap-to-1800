# Books and Courses

- **Competitive Programmer's Handbook** by Antti Laaksonen (free PDF): https://cses.fi/book/book.pdf . Best first book; covers complexity, sorting, DP, graphs, math.
- **Guide to Competitive Programming** by Antti Laaksonen: expanded version of the handbook.
- **Competitive Programming 4** by Steven and Felix Halim: broad reference.
- **Introduction to Algorithms (CLRS)**: deep reference for later.
- **ITMO Academy on Codeforces EDU**: https://codeforces.com/edu/courses
- **USACO Guide**: https://usaco.guide/

Suggested use: read the Handbook chapters that match each topic note while working through [[Phase 0 - Foundations]] and [[Phase 1 - Core Techniques]].
