# Phase 1 - Core Techniques

Sorting, binary search, two pointers, prefix sums, greedy and constructive thinking. These solve most Div 3 and Div 2 A-C problems.

- **When:** Dec 2026 - Feb 2027
- **Rating range:** 900 -> 1200

## Exit criteria

- [ ] Div 3 A-C solved in most rounds.
- [ ] You can implement binary search on answer and two pointers from memory.
- [ ] Rating at least 1000.
