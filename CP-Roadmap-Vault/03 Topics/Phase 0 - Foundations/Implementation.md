## What to learn

- Translate the statement literally into code, then simplify.
- Grid problems: direction arrays `dx[]`, `dy[]`, bounds checks, 0-indexed versus 1-indexed.
- String and array manipulation, counting, frequency arrays, simulation of processes step by step.
- Case analysis: list all cases on paper, handle each separately, test the boundaries (n = 1, all equal, max values).
- Write small helper functions instead of one long `solve()`.

## Common pitfalls

- Off-by-one with 0/1 indexing.
- Not reading the output format (spaces, YES/NO case).
- Handling only the sample cases.
