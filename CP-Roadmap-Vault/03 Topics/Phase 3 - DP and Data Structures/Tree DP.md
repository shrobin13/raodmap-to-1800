# Tree DP

> Tree DP is the standard way to solve counting and optimization on rooted trees.

**Unlocks:** Nothing further in this roadmap

## What to learn

- Root the tree, compute dp on children and combine.
- Subtree sizes, diameter, independent set, matching.
- Rerooting DP (intro) for answers from every root.

## Common pitfalls

- Recursion depth on chain-shaped trees.
- Mixing up parent and child in the combine step.
