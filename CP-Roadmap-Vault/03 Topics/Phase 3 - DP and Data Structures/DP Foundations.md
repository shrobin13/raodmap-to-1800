## What to learn

- State, transition, base case, order of evaluation.
- Top-down memoization vs bottom-up tabulation.
- 1D DP: stairs, coin change, counting ways.
- Recover the actual solution with parent pointers.
- Space optimization (rolling arrays).
- Habit: write the state in words ('dp[i] = best answer using the first i items').
