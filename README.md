## 🎯 What Is This?

This is a **complete competitive programming roadmap** packaged as an Obsidian vault — an interconnected graph of notes that guides you, step by step, from absolute beginner all the way to **Codeforces Expert (rating 1800)** in 14 months.

It is **opinionated on purpose.** Instead of drowning you in resources, it gives you one clear path: which topics to study, in which order, for how many days, with which problems to solve — and exactly when to move on.

> **Goal:** Codeforces rating 1800 by December 2027, starting November 2026.

## 🚀 Getting Started in 3 Steps

### Step 1 — Get the vault

```bash
git clone https://github.com/shrobin13/raodmap-to-1800.git
```
Or click **Code → Download ZIP** and extract it.

### Step 2 — Open in Obsidian

> Don't have Obsidian? Download it free at [obsidian.md](https://obsidian.md/)

1. Launch Obsidian
2. Click **Open folder as vault**
3. Select the `CP-Roadmap-Vault` folder *(not the repo root)*
4. Open **`00 Home.md`** — your launchpad

### Step 3 — Explore the graph

Press `Ctrl + G` (`Cmd + G` on Mac) to open **Graph View** and see every note and how they connect. Graph colors are pre-configured:

| Color | Meaning |
|:---:|:---|
| 🟡 Yellow | Hub notes — entry points for each section |
| 🩵 Teal | Strategy notes |
| 🟣–🔵–🟢 Phase colors | Topic notes, one shade per phase |
| 🩷 Pink | Resource notes |

Use `Filters → Tags` or search `tag:#phase-1` to isolate a single phase in the graph.

## 💡 The Five Rules

> These aren't motivational fluff. They're the actual principles baked into the structure of this vault.

1. **Solve > Read.** Ratio: ~60% solving problems, ~20% learning, ~20% contests + upsolving.
2. **Practice at the edge.** Always target problems 100–200 rating above your current level.
3. **Upsolve every contest.** Most rating growth happens *after* the round ends.
4. **Consistency wins.** 2 focused hours daily beats a 10-hour Sunday grind.
5. **Only core topics for 1800.** `optional` and `stretch` topics can wait.

---

## 📅 Daily & Weekly Rhythm

```
─── Sample 2-hour daily block ──────────────────────────────
  10 min  Review Mistake Log from yesterday
  30 min  Study or revise one concept from the current topic
  60 min  Solve problems from the topic practice plan
  10 min  Log solved problems in Problem Log
  10 min  Read an editorial for something you couldn't solve

─── Weekly rhythm ──────────────────────────────────────────
  Mon–Fri  Topic work
  Saturday  Live or virtual rated contest
  Sunday   Upsolve + Weekly Review
```

**Only have 45 minutes?** Solve one problem at your level and write one line in the log. Never skip two days in a row.

## 📊 Progress Tracking (Built In)

The `07 Tracking` folder has everything you need to measure progress:

| Log | What you track |
|:---|:---|
| **Problem Log** | Every problem: platform, rating, tags, result, key idea |
| **Mistake Log** | Every missed idea — reviewed every Sunday |
| **Contest Log** | Contest name, problems solved, rank, rating delta |
| **Rating Tracker** | Monthly target vs. actual — 14 months pre-filled |
| **Weak Spots** | Tick any of the 61 topics you struggle with |
| **Dashboard** | Live Dataview query showing topic status *(optional plugin)* |

Topic notes track their own status via YAML: `todo` → `doing` → `done`.

## 🔧 Customizing the Vault

The vault is **plain Markdown** — reorder topics, change dates, delete sections you don't need. Everything uses wikilinks, so renaming a note propagates automatically in Obsidian.

### Priority Labels

| Label | Meaning |
|:---:|:---|
| `core` | **Required** for reaching 1800 |
| `optional` | Helpful but skippable |
| `stretch` | For Phase 5, after the goal |

### Optional: Dataview Plugin

Install the [Dataview](https://github.com/blacksmithgu/obsidian-dataview) community plugin to unlock the **Dashboard** note — it auto-generates a live table of all 61 topics with their status, phase, priority, and estimated days.
